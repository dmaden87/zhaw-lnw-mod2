Das Glossar erklärt Abkürzungen und Fachbegriffe aus den Prozessen, Leitfäden, Arbeitsanweisungen und Systemhandbüchern. In Klammern steht das Dokument mit weiteren Details.

| **Begriff**                     | **Erklärung**                                                                                                              |
|---------------------------------|----------------------------------------------------------------------------------------------------------------------------|
| **AML / GwG**                   | Anti-Money-Laundering; in der Schweiz Geldwäschereigesetz. Regeln gegen Geldwäscherei und Terrorismusfinanzierung (WE-01). |
| **BDD**                         | Business Direct Debit: Lastschrift zwischen Firmen ohne Widerspruchsrecht; endet am 30.09.2028 (PAY-07).                   |
| **BEN / OUR / SHA**             | Spesenoptionen: Empfänger zahlt alle / Auftraggeber zahlt alle / jede Seite zahlt die eigene Bank.                         |
| **BIC**                         | Business Identifier Code (SWIFT-Code) einer Bank, z. B. für Auslandzahlungen.                                              |
| **camt.029**                    | ISO-20022-Antwort auf einen Rückruf oder eine Nachforschung.                                                               |
| **camt.053**                    | Elektronischer Kontoauszug (Tagesauszug).                                                                                  |
| **camt.054**                    | Avis über einzelne Gutschriften oder Belastungen; Grundlage für den Debitorenabgleich bei QR-Rechnungen.                   |
| **camt.056**                    | Rückrufanfrage für eine bereits versendete Zahlung (Recall).                                                               |
| **CEO-Fraud**                   | Betrug, bei dem sich Täter als Vorgesetzte ausgeben und eine dringende Zahlung verlangen.                                  |
| **Compliance Hold**             | Status in PayHub: Zahlung wegen Screening-Treffer angehalten.                                                              |
| **Cut-off**                     | Annahmeschluss für Ausführung am selben Bankwerktag (Gletscherbank: CHF 15:00, SEPA 14:00).                                |
| **eBill**                       | Digitale Rechnung direkt ins E-Banking; mit Dauerfreigabe oder eBill Direct Debit auch automatisch bezahlbar (PAY-04).     |
| **EDÖB**                        | Eidgenössischer Datenschutz- und Öffentlichkeitsbeauftragter, Aufsicht über den Datenschutz.                               |
| **euroSIC**                     | Schweizer System für Zahlungen in EUR, angebunden an den SEPA-Raum.                                                        |
| **False Positive**              | Fehlalarm im Screening: Ähnlichkeit, aber kein echter Treffer.                                                             |
| **FINMA**                       | Eidgenössische Finanzmarktaufsicht.                                                                                        |
| **IBAN**                        | International Bank Account Number; Schweizer IBAN hat 21 Stellen und beginnt mit CH.                                       |
| **Instant Payment**             | Zahlung, die in Sekunden gutgeschrieben wird, 24/7 (PAY-02).                                                               |
| **ISO 20022**                   | Internationaler Standard für Zahlungsmeldungen (pain, pacs, camt).                                                         |
| **KYC**                         | Know Your Customer: Identifikation und Kenntnis des Kunden.                                                                |
| **LSV+**                        | Lastschriftverfahren mit Widerspruchsrecht; endet am 30.09.2028 (PAY-07).                                                  |
| **Money Mule**                  | Person, die ihr Konto für die Weiterleitung von Betrugsgeldern zur Verfügung stellt.                                       |
| **MROS**                        | Meldestelle für Geldwäscherei; nimmt Verdachtsmeldungen der Banken entgegen.                                               |
| **MT103**                       | Alte SWIFT-Meldung für Kundenzahlungen; seit 22.11.2025 durch pacs.008 ersetzt.                                            |
| **pacs.004**                    | Rückleitung (Return) einer Zahlung.                                                                                        |
| **pacs.008**                    | Interbankmeldung für Kundenzahlungen (Inland, SEPA, SWIFT).                                                                |
| **pacs.009**                    | Interbankmeldung für Zahlungen zwischen Banken; ersetzt MT202.                                                             |
| **pain.001**                    | Zahlungsauftrag vom Kunden an die Bank.                                                                                    |
| **pain.002**                    | Statusmeldung der Bank zum Zahlungsauftrag (angenommen, abgewiesen).                                                       |
| **PayHub**                      | Zahlungsplattform der Gletscherbank (SH-01).                                                                               |
| **QR-IBAN**                     | Spezielle IBAN für QR-Rechnungen mit QR-Referenz; Instituts-ID 30000–31999.                                                |
| **QR-Referenz**                 | 27-stellige Referenz auf der QR-Rechnung zur automatischen Zuordnung.                                                      |
| **QR-Rechnung**                 | Schweizer Rechnung mit Swiss QR Code; seit 21.11.2025 nur strukturierte Adressen (PAY-03).                                 |
| **R-Transaktion**               | Sammelbegriff für Rückweisung, Rückgabe, Rückruf (Reject, Return, Recall).                                                 |
| **Repair-Queue**                | Arbeitsliste in PayHub für Zahlungen mit manuellem Korrekturbedarf (AA-01).                                                |
| **SCOR**                        | Creditor Reference nach ISO 11649 («RF…»); Alternative zur QR-Referenz mit normaler IBAN.                                  |
| **SCT / SCT Inst**              | SEPA Credit Transfer / SEPA Instant Credit Transfer.                                                                       |
| **ScreenGuard**                 | Screening-System der Gletscherbank für Sanktionen und Fraud (SH-02).                                                       |
| **SECO**                        | Staatssekretariat für Wirtschaft; zuständig für Schweizer Sanktionen.                                                      |
| **SEPA**                        | Single Euro Payments Area, einheitlicher Euro-Zahlungsraum.                                                                |
| **SIC**                         | Swiss Interbank Clearing: Zahlungssystem für CHF, betrieben von SIX im Auftrag der SNB.                                    |
| **SIC5**                        | Instant-Payment-Plattform von SIX und SNB.                                                                                 |
| **STP**                         | Straight-Through Processing: Verarbeitung ohne manuellen Eingriff.                                                         |
| **Strukturierte Adresse**       | Adresse in Einzelfeldern (Strasse, Nr., PLZ, Ort, Land); Pflicht in QR-Rechnung und internationalen Zahlungen.             |
| **SWIFT gpi**                   | Dienst zur Verfolgung von SWIFT-Zahlungen in Echtzeit über die UETR.                                                       |
| **Tipping-off**                 | Unzulässige Information eines Kunden über eine Verdachtsabklärung oder -meldung (Informationsverbot).                      |
| **UETR**                        | Unique End-to-End Transaction Reference: eindeutige Referenz einer SWIFT-Zahlung.                                          |
| **Valuta**                      | Datum, ab dem ein Betrag verzinst wird bzw. verfügbar ist.                                                                 |
| **Verification of Payee (VoP)** | Abgleich von Empfängername und IBAN vor der Freigabe einer EUR-Zahlung.                                                    |
| **Vier-Augen-Prinzip**          | Erfassung und Freigabe durch zwei verschiedene Personen (WE-02, LF-04).                                                    |
